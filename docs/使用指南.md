# cursor-zh 使用指南

## 一、exe 用户（推荐）

### 首次运行

1. 从 [Releases](https://github.com/Ver3ce/cursor-zh/releases/latest) 下载 `cursor-zh.exe`，放到一个固定的文件夹（之后词典、配置、日志都会生成在它旁边）。
2. 双击 `cursor-zh.exe`。向导会依次：
   - 自动探测 Cursor 安装位置（注册表 / PATH / 常见目录）。找不到会弹出文件选择框让你手动选 `Cursor.exe`。
   - 写入 `config.json`，释放词典 `dict\zh-CN.json`。
   - 询问是否安装 VS Code 官方简体中文语言包（汉化菜单等 VS Code 底座）。已安装则跳过。
   - 询问是否把显示语言设为 `zh-cn`（写入 `%USERPROFILE%\.cursor\argv.json`，先备份）。
   - 询问是否创建桌面快捷方式「Cursor (中文)」。
3. 向导结束后会以中文界面启动 Cursor。如果 Cursor 此时正在运行（普通方式打开的，没有调试端口），会询问是否关闭它并重新启动——回车即可，未保存的编辑由 Cursor 自动恢复。

### 日常使用

双击桌面「Cursor (中文)」。控制台窗口会最小化运行，保持它开着（关掉 = 停止对新窗口的翻译，已翻译内容保留，Cursor 本体不受影响）。

### 为什么必须先退出 Cursor

Cursor 是单实例程序。已有实例在运行时，新启动的 `Cursor.exe` 会把参数转交给旧实例然后退出，调试端口不会打开。所以每次想用中文界面启动，都要先退干净。若 Cursor 已经在运行且是通过本工具启动的（端口已开），双击 exe 会直接附加，不需要重启。

### 命令行

在 exe 所在目录打开终端：

| 命令 | 作用 |
|---|---|
| `cursor-zh.exe` | 首次进入向导；之后等同于 `start` |
| `cursor-zh.exe setup [--yes] [--no-langpack] [--no-locale] [--no-shortcut]` | 重新运行向导 |
| `cursor-zh.exe start [--force] [-- <Cursor 参数>]` | 启动 Cursor 并注入。`--` 后的参数透传给 Cursor（如项目路径） |
| `cursor-zh.exe attach` | 附加到已用调试端口启动的 Cursor |
| `cursor-zh.exe collect` | 导出所有窗口中未翻译的文案到 `dict\untranslated.json` 后退出 |
| `cursor-zh.exe update-dict` | 从 GitHub 拉取最新词典（唯一会联网的命令；校验通过才覆盖，旧词典备份为 `.bak`） |
| `cursor-zh.exe detect` | 打印探测到的 Cursor 路径、配置状态、显示语言 |
| `cursor-zh.exe uninstall [--restore-locale]` | 删除桌面快捷方式，可选还原显示语言 |

`start` 运行期间控制台可输入：`r` 重载词典、`c` 导出未翻译、`s` 会话数、`q` 退出本工具。

### 文件说明

```
cursor-zh.exe          程序本体（内含 Node 运行时与默认词典）
config.json            配置：Cursor 路径、端口、词典路径、远程词典地址
dict\zh-CN.json        词典（可编辑，保存即热更新）
dict\untranslated.json collect 导出的未翻译文案
logs\cursor-zh.log     运行日志
```

`config.json` 字段：

| 字段 | 默认 | 说明 |
|---|---|---|
| `cursorPath` | 自动探测 | `Cursor.exe` 完整路径 |
| `port` | 9333 | CDP 调试端口，仅监听 127.0.0.1；被占用时改一个即可 |
| `dictionary` | `dict/zh-CN.json` | 词典路径 |
| `watchDictionary` | true | 词典文件变化时自动热更新 |
| `extraCursorArgs` | `[]` | 每次启动 Cursor 附加的参数 |
| `dictUrl` | 仓库 main 分支 | `update-dict` 拉取地址 |

## 二、源码运行（开发者）

需要 Node.js ≥ 18（构建 exe 需要 ≥ 20，Windows）。

```powershell
git clone https://github.com/Ver3ce/cursor-zh.git
cd cursor-zh
npm install
npm run build
node dist/index.js setup        # 同 exe 的向导；快捷方式会指向 cursor-zh.cmd
node dist/index.js start
```

其他脚本：

| 脚本 | 作用 |
|---|---|
| `npm run build` | tsc 编译到 `dist/` |
| `npm run build:exe` | 构建单文件 exe 到 `build/out/cursor-zh.exe`（esbuild → Node SEA → postject） |
| `npm run validate-dict` | 校验词典 |
| `npm run test:e2e` | headless Edge/Chrome 端到端测试；加 `-- --exe build/out/cursor-zh.exe` 同时验证 exe |

## 三、维护词典

### 格式

```json
{
  "skipSelectors": ["head", "script", ".monaco-editor", "..."],
  "attributes": ["title", "aria-label", "placeholder", "alt"],
  "exact": {
    "_分组注释": "",
    "Accept all": "全部接受"
  },
  "patterns": [
    { "match": "^Thought for (\\d+)s$", "replace": "思考了 $1 秒" }
  ]
}
```

- `exact`：原文 trim 后精确匹配；其次大小写不敏感匹配（仅当无歧义）。以 `_` 开头的键是注释。
- `patterns`：JavaScript 正则，整段匹配，`$1` 引用捕获组。exact 命中优先于 patterns。
- 匹配失败时会去掉尾部的 `...` / `…` / `:` 再试一次，所以 `Loading` 一条就能覆盖 `Loading...`。
- `skipSelectors`：这些元素及其后代不翻译。
- 首尾的空白与零宽字符（U+200B/U+2060 等）会自动剥离后匹配并原样保留。

### 补词流程

1. 在 Cursor 里把想汉化的面板都点开一遍。
2. 控制台按 `c` 回车，或运行 `collect`。打开 `dict\untranslated.json`，按出现次数排序。
3. 判断每条属于界面文案还是内容（模型名、文件名、你自己的对话标题不要翻）。
4. 加入 `dict\zh-CN.json`，保存后 1 秒内生效。
5. 想分享给其他人：提 PR 到本仓库，CI 会自动校验。

### 有意不翻译的类别

快捷键（`Ctrl+K`）、模型名（`Claude Opus 5`）、字体名、文件/目录名、shell 命令与变量、产品名（`Cursor`、`GitHub`、`LSP`）、AI 回复正文、你输入的内容。采集器会自动过滤其中大部分。

## 四、故障排查

| 现象 | 原因与处理 |
|---|---|
| 提示"Cursor 已在运行，但不是由本工具启动的" | 你先用普通图标打开了 Cursor。回车让程序关闭并重启它，或加 `--restart` 跳过询问；拒绝的话需手动在任务管理器结束 `Cursor.exe` 后重试 |
| Cursor 启动了，30 秒后提示"未能连接到 127.0.0.1:9333" | ① 有残留进程（同上）② 端口被占：改 `config.json` 的 `port` ③ Cursor 屏蔽了该参数（未见报告；请附 `logs\cursor-zh.log` 提 issue） |
| 界面全是英文，但控制台显示"翻译已生效" | 词典没命中：按 `c` 导出后补词或提 issue |
| 双击 exe / 快捷方式一闪而过 | 出错时程序会停住等待按回车，并把错误写入 `logs\cursor-zh.log`；若连停顿都没有，说明是启动即崩溃，请在终端运行并附输出提 issue |
| SmartScreen 阻止运行 | exe 未签名。"更多信息 → 仍要运行"，或用 `SHA256SUMS.txt` 校验后再运行 |
| 控制台中文乱码 | 仅显示问题。右键标题栏 → 属性 → 字体换为"新宋体"，或运行 `chcp 65001` |
| 更新 Cursor 后部分文案变回英文 | Cursor 改了文案。`update-dict` 拉最新词典，或按 `c` 补词 |

## 五、彻底恢复原状

1. `cursor-zh.exe uninstall --restore-locale`（删快捷方式、还原显示语言）。
2. 删除 exe 所在文件夹。
3. 用原来的方式启动 Cursor。因为从未改动 Cursor 安装文件，不需要重装。
