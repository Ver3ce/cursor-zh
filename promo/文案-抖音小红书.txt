【标题】
Cursor界面一键中文｜Agent面板也能汉化

【正文】
用 Cursor 写代码的人应该都碰到过：
菜单变成中文了，左边 Agent 面板还是 New Chat、Search、Settings 一排英文。

不是你没装语言包。
官方中文包只管 VS Code 那一层，Cursor 自己的界面它覆盖不到。

我用的是开源工具 cursor-zh：
· 一个 exe，双击走完向导
· 运行时翻译，不改 Cursor 安装文件
· 更新之后一般还能用，不用重装破解包
· 开源免费，目前只支持 Windows

装完以后桌面会有「Cursor（中文）」。
日常从这里启动，Agent / Settings / 菜单可以一起看中文。

注意两点：
1. Windows 可能提示未知发布者，点「更多信息 → 仍要运行」。exe 没做代码签名，这是开源小工具的常见情况。
2. 编辑器、终端、AI 回复正文故意不翻译，避免把代码和对话搅乱。

GitHub 搜：Ver3ce/cursor-zh
封面和图里的仓库名就是它。
